# 日次売上記録＆週次レポート自動送信スクリプト

Google スプレッドシートの売上データを自動で記録し、週ごとの集計結果と「次の日本の祝日」を自分のメールアドレス宛に通知する Google Apps Script (GAS) です。

---

## 📋 準備するもの

スプレッドシート内に以下の2つのシートを用意してください。

1. **`本日の売上`** シート  
   - **B1セル**：入力用の当日の売上金額を配置
2. **`売上ログ`** シート  
   - **A列**：日付が自動挿入されます
   - **B列**：売上金額が自動追記されます（1行目はヘッダー推奨）

---

## 🛠️ 機能一覧と使い方

### 1. 日次売上の追記スクリプト (`appendDailySales`)

「本日の売上」シートのB1セルに入力された金額を取得し、「売上ログ」シートの最下行に【日付・売上金額】を追加します。

* **使い方**：日々の売上入力後に手動実行、または毎日夜間のトリガー（自動実行）を設定して使用します。

### 2. 週次売上レポートメール送信スクリプト (`sendWeeklySalesReport`)

「売上ログ」シートの売上を自動集計し、外部APIから取得した「次の祝日」情報とともにログイン中のGoogleアカウント宛へメール送信します。

* **主な機能**：
  * **自動集計**：「売上ログ」シートのB列（2行目以降）を合計し、`¥1,000` 形式にフォーマット
  * **祝日情報の取得**：外部API（`holidays-jp.github.io`）と連携し、今日以降で一番近い祝日を抽出（通信失敗時の自動リトライ機能つき）
  * **メール自動送信**：集計結果と次の祝日を本文にまとめて自分宛てに送信
* **使い方**：週末などの定期実行トリガーにセットして運用します。

---

## 💡 設定・運用のコツ

* **トリガー設定**：GASエディタの「トリガー（時計アイコン）」から、定期実行を設定すると全自動化できます。
  * `appendDailySales` ➔ 毎日 23:00〜24:00
  * `sendWeeklySalesReport` ➔ 毎週金曜日 18:00〜19:00
