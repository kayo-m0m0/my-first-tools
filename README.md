# 週次売上レポート自動送信ツール

「売上ログ」シートの集計結果と次の日本の祝日情報を、自分のGmailへ自動送信するGoogle Apps Script (GAS) です。

## できること
- 「売上ログ」シートのB列から売上合計金額を自動集計（¥1,000形式に整形）
- 祝日API（holidays-jp）と連携し、今日以降で一番近い祝日を取得（通信エラー時の自動リトライ機能つき）
- 集計結果と祝日情報をまとめたレポートメールを自分宛てに送信

## 使い方
1. Googleスプレッドシートで「拡張機能」→「Apps Script」を開く
2. `sales-report.js` にコードを貼り付ける
3. 一度 `sendWeeklySalesReport` を手動実行してアクセス承認を行う
4. トリガー（時計アイコン）から、任意の曜日・時間に定期実行を設定する

## 注意点
- スプレッドシート内に「売上ログ」という名前のシートが必要です
- 売上金額は「売上ログ」シートのB列（2行目以降）を集計します
- 初回実行時のみ、Googleアカウントのアクセス許可画面が表示されます
